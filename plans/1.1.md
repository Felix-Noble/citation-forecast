# Plan 1.1 — Migrate `preprocess`, `describe`, `engineer` to v1.0 config shape

> **Scope:** complete the migration of the remaining old-code apps so that the
> Phase-0 PEP 562 shim in `src/config/env.py` can be removed. This plan is
> authored in Phase 7 of plan 1.0 (v3) and implemented afterwards.

---

## 1. Goal

All apps read machine settings through `config.env.load_env(...)` and never
`import config` for singleton values. Once this is true, the temporary
`__getattr__` shim in `src/config/env.py` (exposing `TRACKING_URI`, `RAW_LOC`,
`STAGED_LOC`, `ARTIFACT_LOC`, and `EXPERIMENT`) can be deleted.

Non-goals: adding new ML functionality, changing dataset IPC caching, real S3,
model architectures, or the experiment-file format itself.

---

## 2. Current state

After plan 1.0 (v3) phases 0–7:

- `src/apps/train.py` and `src/apps/eval.py` are fully rewired: they build
  `Env` from CLI overrides, construct `RunContext`, and load an `Experiment`.
- `src/apps/preprocess.py`, `src/apps/describe.py`, and
  `src/apps/engineer.py` still rely on the Phase-0 shim:
  - `describe.py` imports `from config import env` and reads `env.STAGED_LOC`.
  - `engineer.py` had a dead `import config` removed in Phase 7 but is
    otherwise untouched.
  - `preprocess.py` does not currently touch project config, but it hard-codes
    paths/defaults and should be brought onto the same `load_env` path for
    consistency.
- `src/config/env.py` still exposes legacy module-level names via PEP 562
  `__getattr__`. This was intentionally kept only until these apps migrate.

---

## 3. Locked decisions

| # | Decision |
|---|----------|
| K1 | Apps use `config.env.load_env(cli_overrides)`; no `import config` anywhere. |
| K2 | `describe`/`engineer`/`preprocess` get the same four `[env]` CLI override flags as train/eval (`--tracking-uri`, `--raw-loc`, `--staged-loc`, `--artifact-loc`) for consistency, even if some are unused. |
| K3 | Path defaults come from `config/config.toml [env]`; CLI overrides replace them. |
| K4 | Once all three apps are migrated, delete the `__getattr__` shim in `src/config/env.py` entirely. |
| K5 | No shared base class or config module for these apps; each app owns its own argument parsing and env consumption. |

---

## 4. Target architecture

```text
src/config/env.py         # Env dataclass + load_env(); no __getattr__ shim
src/apps/describe.py      # load_env + explicit filter arg/expression
src/apps/engineer.py      # load_env + explicit input/output paths
src/apps/preprocess.py    # load_env + explicit input/output paths
```

---

## 5. Per-app migration

### 5.1 `describe`

- Add `ctx: typer.Context` parameter if not already present.
- Add the four `[env]` CLI override flags.
- Build `env = load_env(overrides={...})` at the top of `main`.
- Replace `env.STAGED_LOC` usage with `env.staged_loc`.
- The dataset filter currently hard-coded in Phase 7 should become an optional
  CLI flag (e.g. `--min-cited-by-count`, `--min-referenced-works`) or accept a
  raw Polars expression string, so `describe` no longer needs to know the train
  dataset schema. The minimal Phase-7 inline expression is a stop-gap only.
- Log env-derived paths for user visibility.

### 5.2 `engineer`

- Add `ctx: typer.Context` and the four `[env]` CLI override flags.
- Build `env = load_env(...)`.
- Resolve `input_path` / `input_dataset` against `env.raw_loc` / `env.staged_loc`
  explicitly. Do not fall back to `config.data` defaults.
- Export engineered output under `env.staged_loc / "engineered"` unless an
  explicit output path is given.
- Remove any remaining accidental references to `config` module attributes.

### 5.3 `preprocess`

- Add the four `[env]` CLI override flags.
- Build `env = load_env(...)`.
- Default `origin` to `env.raw_loc` when not provided; default destination to
  `env.staged_loc / <name>`.
- Keep all preprocessing logic unchanged; only path resolution and env loading
  change.

---

## 6. Shim removal

After the above apps are verified:

1. Delete `_default_env()` and `__getattr__()` from `src/config/env.py`.
2. Remove the `typing.Any` import if it becomes unused.
3. Verify no `from config import env` reads legacy module-level names and no
   `import config` remains.

---

## 7. Verification

```bash
basedpyright src/apps/describe.py src/apps/engineer.py src/apps/preprocess.py src/config/env.py
citef describe -d <dataset> --staged-loc /tmp/data
citef engineer -d <dataset> -o /tmp/engineered --staged-loc /tmp/data
citef preprocess <origin> -n <name> --raw-loc /tmp/raw --staged-loc /tmp/data
```

Expected: each app runs without `AttributeError` on `config.*` and without
triggering the `env.py` `__getattr__` shim.
